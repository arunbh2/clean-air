Feedback loops

In short

A feedback loop is a chain of effects that returns to where it started, so a harm can reinforce itself. The map shows {{ loops|length }} loops. Each link in a loop has its own evidence, but none of these loops has been studied from start to finish, so each is an interpretation to test, not a finding.

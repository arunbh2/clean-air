---
title: "Corrections"
summary: "How to report an error and how corrections are recorded."
---

If you find a factual error, a broken source or a misread study, please open an issue in the public repository using the "Correction" template. Include the claim ID (for example C016) or the page address, the source you believe is correct, and its date.

Corrections are checked against the original source. Each one is recorded in the register below with the earlier wording where it was kept, the reason and the date, and the corrected record flows to every page, Markdown copy, data download and evidence pack in the same build. A withdrawn claim is never deleted: it stays in the claim register marked as withdrawn. Every change is also visible in the repository history, and the [update feed](../feed.xml) lists them by date. The method behind the Phase 2 corrections is in the [verification record](../evidence/verification.html).
